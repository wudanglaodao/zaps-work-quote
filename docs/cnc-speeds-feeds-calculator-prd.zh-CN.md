## 1. 用户价值与核心场景

### 1.1 核心痛点
- 数控铣床/雕刻机操作工在加工新零件时，必须设定合理的 **主轴转速 (Spindle RPM)** 和 **走刀进给速度 (Feed Rate)**。
- 设定错误会导致断刀、机床过载抖动、工件表面粗糙度差甚至报废。
- 传统操作需要查阅各类刀具厂商复杂的推荐线速度 $V_c$ 和每齿进给 $f_z$ 表格。

### 1.2 解决方案
打造最简洁直观的切削参数求解器：
1. 选择被加工材质与刀具规格（直径、刃数、涂层）。
2. 选择工序模式（开粗高效切削 / 精加工高表面光洁度 / 钻孔开槽）。
3. 立即得到：主轴转速 (RPM)、进给速度 (mm/min)、材料去除率 (MRR)、预估切削功率需求。
4. 提供 **“工时估算模式”**：输入加工路径总长度或去除体积，直接估算出单件机加工工时，并一键传递给 CNC 报价器。

## 2. 数据库与工程计算公式

### 2.1 材质与切削线速度 ($V_c$) 预设数据库 (硬质合金刀具基准)
| 材质类别 | 代表牌号 | 推荐线速度 $V_c$ (m/min) | 推荐每齿进给 $f_z$ (mm/tooth) |
| :--- | :--- | :--- | :--- |
| **铝合金** | 6061-T6, 7075-T6 | $180 \sim 450$ | $0.03 \sim 0.12$ |
| **低碳钢/中碳钢** | 45#钢, Q235, 1018 | $90 \sim 180$ | $0.02 \sim 0.08$ |
| **不锈钢** | SUS304, SUS316 | $50 \sim 110$ | $0.015 \sim 0.05$ |
| **黄铜 / 铜合金** | C3604, H59 | $120 \sim 260$ | $0.03 \sim 0.09$ |
| **工程塑料** | POM(赛钢), 亚克力, 尼龙 | $150 \sim 400$ | $0.04 \sim 0.15$ |
| **钛合金** | TC4, Ti-6Al-4V | $30 \sim 65$ | $0.015 \sim 0.04$ |

### 2.2 核心计算公式
1. **主轴转速 (Spindle Speed, $N$)**：
   $$N = \frac{V_c \times 1000}{\pi \times D} \quad (\text{RPM})$$
2. **走刀进给速度 (Feed Rate, $F$)**：
   $$F = N \times Z \times f_z \quad (\text{mm/min})$$
3. **材料去除率 (Material Removal Rate, $MRR$)**：
   $$MRR = \frac{a_p \times a_e \times F}{1000} \quad (\text{cm}^3/\text{min})$$
   *(其中 $a_p$ 为轴向切深 mm，$a_e$ 为径向切宽 mm)*
4. **预估切削功率需求 ($P$)**：
   $$P \approx \frac{MRR \times k_c}{60} \quad (\text{kW})$$
   *(其中 $k_c$ 为材质单位切削抗力系数)*

## 1. 需求背景与用户痛点

### 1.1 现状痛点
在小五金加工、亚克力打样、钣金激光切割店的日常运营中，客户通常发来 `.dxf` 或 `.svg` 格式的 2D CAD 零件图纸询问报价。
- 激光切割的核心成本取决于：**总切割线长（机时耗电）**、**打孔次数（穿孔耗损）** 和 **零件包络用料面积**。
- 当前老板必须在电脑上启动庞大的 CAD 软件（如 AutoCAD、LightBurn），手动测量周长并计算孔数，再将数字抄到计算器中，单次报价需耗费 3~5 分钟。

### 1.2 解决方案
在网页端实现纯前端 CAD 几何解析器：
1. 用户直接将 `.dxf` 或 `.svg` 拖入浏览器。
2. 浏览器端（零数据上传，保护客户商业图纸隐私）秒级解析并可视化 2D 轮廓。
3. 自动计算：**总切割线长 (mm)**、**穿孔总数 (Pierces)**、**用料面积 (cm²)**、**包络尺寸 (L×W)**。
4. 一键将参数注入到激光切割报价计算器，选择板材厚度/材质即可秒级生成并导出 PDF 报价单。

## 2. 核心功能与技术方案

### 2.1 架构设计
- **图纸解析层**：
  - DXF：使用轻量前端开源库（如 `dxf-parser` 或 WASM 几何求解器），提取 ENTITIES（LINE, ARC, CIRCLE, LWPOLYLINE, SPLINE）。
  - SVG：基于 SVG Path 数据（`d` 属性）计算 `getTotalLength()` 与内联图形几何。
- **几何计算算法**：
  - **总线长**：各几何图元长度累加（直线距离、圆弧弧长、多段线分段长度、样条曲线拟合长度）。
  - **穿孔次数**：独立闭合/开环轮廓数量统计（每个独立闭合路径需一次激光穿孔打火）。
  - **包络盒 (Bounding Box)**：计算所有顶点的 Min/Max X, Y，得出建议矩形开料尺寸。
- **渲染交互层**：
  - HTML5 Canvas / SVG 即时渲染零件线条（外轮廓与内孔区别高亮），支持鼠标滚轮缩放、拖拽平移。
- **计算器联动**：
  - 自动将测得数据填入 `LaserCuttingCalculator` 的对应字段。
